
# 📝 To-Do List App

A modern, responsive, and user-friendly **To-Do List Web Application** built using HTML, CSS, and JavaScript. This app helps users manage daily tasks, track completed activities, and save their task list directly in the browser using Local Storage.

## ✨ Features

- ➕ Add new tasks easily.
- ✅ Mark tasks as completed.
- ❌ Delete individual tasks.
- 🗑️ Clear all tasks with confirmation.
- 🔢 Automatically update the task counter.
- 💾 Save tasks using browser Local Storage.
- 🔄 Restore saved tasks after refreshing the page.
- ⌨️ Add tasks by pressing the Enter key.
- 📱 Responsive design for mobile and desktop.
- 🎨 Modern dark theme with an orange gradient background.
- ✨ Smooth task animations and hover effects.

## 🛠️ Technologies Used

- **HTML5** — Structures the application.
- **CSS3** — Provides styling, responsive layouts, and animations.
- **JavaScript** — Handles task management and user interactions.
- **Local Storage** — Stores tasks in the browser.
